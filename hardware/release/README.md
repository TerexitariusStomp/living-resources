# EcoCell Ocean — Engineering Release

This directory is the manufacturing package for the ocean-capable EcoCell
node: pressure-rated submerged electronics body plus a minimal-signature
tether float (GPS, antenna, solar). One serialized design covers both the
tether-float and fully submerged-pod forms — the same node electronics,
deployment role chosen by firmware flags.

## Release levels

- **R0 — prototype fab package.** A supplier-reviewable package a fab can
  quote and build from: native KiCad sources, netlist, DSN, Gerbers +
  drill, CPL, controlled BOM, assembly + harness drawings, stack-up/fab
  drawing, test plan, unit traveler, and this README with a checksummed
  manifest. R0 does **not** claim validated pressure rating, ecological
  benefit, or field performance — it claims the design files are
  consistent, DRC-clean, and buildable.
- **R1 — validated build.** R0 plus: assembled units pass TEST-PLAN,
  pressure/leak spec verified on the hull, Salton Sea serialized trial
  complete, DFM/DFT review closed with the supplier.

## Regenerating the electrical package

```
python3 tools/pcb/gen_ocean_sch.py          # writes electrical/ecocell-ocean.net
python3 tools/pcb/gen_ocean_pcb.py          # placement + DSN export
STITCH=1 python3 tools/pcb/gen_ocean_pcb.py # adds the stitch router (slow)
POST_ONLY=1 python3 tools/pcb/gen_ocean_pcb.py
    # resume: re-run only the post-attach island pass on the saved board
```

Fabrication rules baked into the generator: ≥0.2 mm clearance, ≥0.15 mm
track, 0.5/0.3 mm vias, ≥0.5 mm copper-to-edge, mounting-hole and
ESP32 antenna keepouts.

## ECO procedure

1. Describe the change in `CHANGELOG.md` (rev, scope, reason, risk).
2. Regenerate affected artifacts from source — never hand-edit Gerbers,
   CPL, or the manifest.
3. Re-run DRC on the board and the repo checks (`make test`,
   `make check-custom-budget`); record results in the manifest.
4. Re-hash every shipped artifact into `manifest.json` and bump the
   package checksum.
5. A second reviewer signs off before the package is quoted to a fab.

## Honest-status notes

- The board currently validates as *routed*, not *fabrication-ready*:
  DRC must report 0 errors/0 unconnected before Gerbers are exported
  and the "KiCad PCB" row moves to verified.
- Acoustic playback hardware (emit lane) is consent-gated in firmware
  and policy; no ecological effect is claimed from this package.
