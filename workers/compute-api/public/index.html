Compute you can check.Every task ships its own proof.

This service runs deterministic leaky-integrate-and-fire simulation over real EM-derived connectomes — preserved biological wiring, not a learned model. Each task returns a receipt with a trace_digest and a content address (task_said). Anyone can replay the declared input through the declared wiring and get the identical digest — POST /verify does exactly that.

Honest scope: this is deterministic simulation over published connectome data. No organism computed this answer; the wiring is the artifact.

API

GET  /info                service description
GET  /connectomes         list the 15 wired substrates
POST /task                {connectome, features|input} → receipt
POST /verdict             {connectome|all, features} → verdicts
POST /verify              receipt → {verified}
GET  /receipts            issued receipt addresses
GET  /receipts/{said}     fetch a stored receipt
