# Retroactive public-goods funding — watch notes

These lanes pay *retroactively* for demonstrated public-goods impact —
they're a harvest, not seed capital. The play is: keep shipping,
publish impact publicly, apply when a round opens with receipts to show.

## Optimism RetroPGF / Retro Funding

- Funds open-source impact on the Superchain — dev tooling, public
  goods infrastructure, governance.
- **Fit:** medium. The receipt/verification infra qualifies as public
  goods only if the project builds on or meaningfully serves the
  Optimism/Superchain ecosystem — a bare ecological-commons pitch
  doesn't score. If a future round broadens scope, revisit.
- **Watch:** rounds post on retrofunding.optimism.io + governance forum.

## Octant

- Epoch-based public-goods funding driven by GLM lockers' rewards.
- **Fit:** good once there's public impact to point at — the AGPL
  commons + live receipted ledger are exactly the "fundable public
  good" shape. Listing on Giveth + visible onchain presence helps.
- **Watch:** epoch windows; requires an eligible project listing.

## Giveth (done — `giveth-listing.md`)

- Immediate: publish listing → GIVbacks eligibility → round inclusion.

## The honest dependency

Retro funding scores *demonstrated* impact. Before applying anywhere:
public impact page (receipt counts, adopters, datasets onboarded,
field evidence SAIDs). The ledger at templeearth.cc/receipts is the
raw material — package it as an impact report when rounds open.
