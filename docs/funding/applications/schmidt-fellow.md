# Schmidt Futures / AI-in-Science — application draft

Fellowship-shaped program — frame the person + project, not a product.

## Title

Replay-verified computation for scientific integrity

## Framing

Science's reproducibility crisis is a compute-evidence problem: results
are reported, not re-executed. This project builds self-evidencing
computation — tasks whose output includes a content-addressed trace
that any auditor replays bit-for-bit — demonstrated on deterministic
inference over 15 real organism connectomes, with measured efficiency
(RAPL deltas, op-models, honesty-tiered reporting) published as open
methodology for any lab to adopt.

## The AI-in-Science hook

Inference increasingly intermediates measurement (bioacoustic
classifiers, eDNA pipelines). Our receipt layer binds model inputs,
code identity, and outputs into one verifiable chain — "the model said
X" becomes "here is the replayable trace that produced X."

## Deliverables

- Open verifier (any lab replays any receipt)
- Methodology paper: tiered measurement reporting for compute claims
- Integration pilot with an existing bioacoustics pipeline

## Fit

Schmidt funds tools that change how science works, not companies.
Lead with methodology, not the product roadmap.
