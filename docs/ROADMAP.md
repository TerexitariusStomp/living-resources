# ROADMAP — from sensing cell to living cloud

Lanes graduate experiment → offer only when their evidence SAID lands in
the gate book. Emit/cast/store graduate on consent. Everything else waits.

## v1 — the sensing cell (current)

Universal node + edge + Playnet: `sense`/`fleet` lanes live; receipts +
credit flowing; camera/audio/env multimodal; store-and-forward over
Reticulum.

**Gate:** E0 passes.

## v1.5 — the federated commons

Multiple cells, multiple sites, Reticulum mesh federation; detection
ledger + lossless evidence store; guardian cohorts per site; first MRV
data contracts.

## v2 — head lanes

- `ultra` → plant clicks (E2)
- `hydro` at scale → reef cells, shore/dock + moored float
- `c4d` → biofilm readout (E3)
- `cam`/`env` lanes graduate to first-class offers on E0 field data

## v3 — the read/write living interface

- `emit`/`cast` exercised under consent where warranted: acoustic
  enrichment, stimulus→response experiments, underwater relay between
  submerged pods and a moored float.
- `store`/`compute` on node hardware (SD storage legs, edge offloads) —
  consent-gated downlink lane.
- Wild-consortium reservoir compute: research lane, E-gated, no claims
  ahead of receipts.

## Funding track

- **Now → E0:** self-funded, ~$100 total hardware.
- **Post-E0:** Seeed Co-Create submission (EcoCell — open node, they
  manufacture, royalty to the commons); Rewilding the Web pilot ($1K).
- **Validated fleet:** WILDLABS Awards 2027 ($10–50K), Schmidt Marine
  Technology Partners (ocean-observing thesis fit), Wildlife Acoustics
  quarterly equipment grants, Brainforest Venture Program.
- **Mature:** MRV data contracts (CSRD/biocredit markets), biodiversity
  credit origination royalties.

## Procurement-readiness track

Tenders are episodic and close fast — readiness wins them, not chasing:

- Register supplier profiles + saved-search alerts: Find a Tender (UK),
  eTenders (IE), SAM.gov + state portals (US).
- Tender-attachable datasheet (from spec §2 BOM + E0 results).
- CE/UKCA marking for shipping product (ESP32 module's radio cert
  simplifies; product-level EMC test still required).
- Comparables on file: AudioMoth ~$100/unit, 13,894 units/3yr; Forestry
  England paid ~£640/unit to incumbents; we price at a fraction.
